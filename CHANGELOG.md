# Changelog

All notable changes to the Specula BOS documentation will be documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [2.2.0] - 2026-10-21

### Changed
- `workshops/worldbuilding-collaborativo`: four scenarios built with a construction rule (four generic futures, closed megatrends shared, one scenario against the strongest declared value, at least one implausible at first reading, horizon 10–15 years); four teams with external participants; white spaces labelled trend or countertrend.
- `workshops/archeologia-brand`: corpus from documents, strategic interviews, official futures, counterexamples and a measure of change; Value Stress Test on the operational form of each value, judged by people who did not build the scenarios, with Causal Layered Analysis as second method; at least one candidate value must fall.
- `workshops/brief-sotto-stress`: preliminary meetings with threshold sheet, opening exercise and speaking rules; session closes with written consensus on research question, time window and working rules.
- `workshops/mappa-segnali-deboli`: declared grid with the research question at the centre; human collection, AI for correlations; signals tagged with source and domain.
- `workshops/dal-prototipo-al-protocollo` (now 4 hours): preferable future and backcasting before the protocol; decision criteria as hypotheses with expected effect and review date.
- `workshops/calibrazione-radar`: thresholds leaning toward reopening, combination rules, escalation times scaled to signal speed.
- `workshops/audit-memoria`: expected versus observed effects; drift classification check.
- `docs/03_seven-layers`: layers 01, 02, 03, 05, 06 aligned with the workshops.
- `docs/04_circolo-di-sintesi`: new section on functions, voting rules and disagreement, with the framework Governance Charter as canonical source; Brand Alchemist synthesis rules.
- `docs/05_memory-architecture`: Decision Memory as Decision Log with expected effect, review date and observed effect.
- `docs/06_system-lifecycle`: drift classification (error, superseded model, learning).
- `docs/08_definition-of-done`: Guardian as periodic external review that presupposes autonomy.
- `templates/brand-governance-playbook`: Decision Log table and drift classification inside sections 3 and 4.
- `README.md`: version and references to `specula-method` 2.0 and `specula-framework` 1.3.
- `docs/00_index`: duration of From Prototype to Protocol; playbook stress-test column refers to four scenarios.

Both languages updated for every file.
